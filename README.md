# test_calculator

GitHubの基本操作を学ぶための、シンプルな計算機ツールです。

## 目的

以下のGitHub操作を実践しながら学びます。

- ブランチの作成と切り替え
- Issueによる作業管理
- Pull Requestの作成とレビュー
- develop、mainへのマージ
- Github Actionによる自動テスト(CI/CD)

## ブランチ構成

main：開発の節目でマージする安定版
develop：開発の中心となるブランチ
feature/*：各Issueごとの作業ブランチ

## 開発環境

Visual Studio Code
Git
GitHub
